# Ashford Dental Centre — Homepage Redesign

## Website Overview

Ashford Dental Centre is a Singapore dental practice group with four clinics in Upper Thomson, Serangoon, Simpang Bedok and Jalan Kayu. It provides routine and family dentistry, restorative treatment, orthodontics, oral surgery and emergency dental care. The homepage redesign is aimed at current and prospective patients who need to choose a clinic, book an appointment or find the appropriate route for urgent care. It brings booking forward, makes branch information easier to compare and distinguishes emergency care from routine appointments.

## Main Improvements

1. **More prominent appointment booking**
   - **Changed:** Added **Book an appointment** to the hero and linked it directly to the verified appointment form. On mobile, **Book appointment** and **WhatsApp** remain visible while visitors scroll.
   - **Addresses:** The previous opening banner prioritised clinic locations, while the main appointment prompt appeared farther down the page.

2. **All four clinic locations visible together**
   - **Changed:** Added four clinic cards directly after the hero, each showing its address, a direct call link and a branch page link.
   - **Addresses:** Previously, branch details appeared one at a time in tabs, requiring visitors to switch between them to compare locations and phone numbers.

3. **A distinct route for urgent dental care**
   - **Changed:** Added a dedicated **Urgent dental care** route, with a branch call option and a clearly labelled link to Ashford’s emergency dentistry page.
   - **Addresses:** The previous emergency section used the generic **Set An Appointment** label, which did not clearly communicate that it led to urgent-care information.

## Design Improvements

- **Clearer homepage priorities:** Appointment booking is presented in the hero rather than being left farther down the page.
- **More scannable branch layout:** Four clinic cards show location and contact details together, replacing the need to compare tabbed content.
- **Consistent, actionable contact details:** Each branch card pairs its address with a direct call link and branch page.
- **Improved mobile access:** Booking and WhatsApp actions stay visible while scrolling on phones.
- **Clearer action labels:** Routine booking and urgent dental care have distinct routes and wording.
